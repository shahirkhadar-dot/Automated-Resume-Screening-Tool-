# Automated Resume Screening Tool 📄

## 📌 About
A Python-based project that automates resume screening by matching candidate resumes with job descriptions and ranking candidates based on relevant skills.

## 🚀 Features
- PDF and DOCX resume extraction
- Text preprocessing
- Skill identification
- Job description matching
- Resume scoring and ranking
- Candidate shortlisting
- CSV report generation

## 🛠️ Technologies
- Python
- Pandas & NumPy
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Regex
- PyPDF2 / python-docx

## ⚙️ Workflow
Resume Upload → Text Extraction → Skill Matching → Score Calculation → Candidate Ranking → Report Generation
